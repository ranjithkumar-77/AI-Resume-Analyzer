# 📄 AI Resume Analyzer

## 📌 Project Overview
AI Resume Analyzer is a Spring Boot web application that analyzes resumes based on a job description. It calculates the ATS score, finds matching and missing skills, suggests improvements, recommends jobs, generates ATS-friendly resumes, and allows users to download reports.

## ✨ Features
- User Registration & Login
- Dashboard with Resume Statistics
- Upload Resume (PDF)
- Resume History
- ATS Score Calculation
- Resume & Job Description Matching
- Match Score
- Skills Extraction
- Missing Skills Detection
- AI Resume Suggestions
- ATS Optimized Resume Generation
- Resume Templates (Modern, Classic, Executive)
- Download Improved Resume (PDF)
- Download ATS Report (PDF)
- Job Recommendations
- Admin Dashboard
- Recruiter Dashboard

## 🚀 How to Run
1. Clone the repository.
2. Open the project in VS Code or Eclipse.
3. Build the project using Maven.
4. Run the Spring Boot application.
5. Open your browser:
   http://localhost:8080
